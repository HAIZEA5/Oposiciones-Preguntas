Q Un navegador web es:
= Un programa que permite acceder y visualizar páginas web
- Un motor de búsqueda
- Un proveedor de acceso a internet
- Un antivirus
E Ejemplos: Chrome, Firefox, Edge o Safari. Google o Bing son motores de búsqueda.
R Navegación

Q La dirección única de una página web que se escribe en la barra de direcciones se llama:
= URL
- IP
- DNS
- HTML
E Por ejemplo, https://www.getxo.eus.
R Navegación

Q Que una dirección web empiece por «https» indica que:
= La comunicación entre el navegador y el sitio está cifrada
- La página es oficial de una Administración
- La página no tiene publicidad
- La página está libre de virus
E El candado de la barra de direcciones indica la conexión segura, pero no garantiza que el sitio sea fiable.
R Navegación segura

Q Guardar una página web para volver a ella fácilmente se hace con:
= Los marcadores o favoritos
- El historial
- Las cookies
- La caché
E El historial registra automáticamente las páginas visitadas.
R Navegación

Q La navegación privada o de incógnito:
= No guarda el historial, las cookies ni los datos de formularios en el equipo al cerrar la ventana
- Hace que nadie pueda saber qué páginas se visitan
- Oculta la dirección IP a todos los sitios
- Protege frente a cualquier virus
E La empresa, el proveedor de internet o los sitios visitados pueden seguir viendo la actividad.
R Navegación privada

Q Las cookies son:
= Pequeños archivos que los sitios web guardan en el navegador para recordar información del usuario
- Virus que se instalan al navegar
- Copias de seguridad de las páginas
- Programas para bloquear anuncios
E Los sitios deben pedir consentimiento para las cookies no necesarias.
R Navegación
